# 🪵 Kotaiah WoodCraft – Carpenter Business Website

A modern, fully responsive business website built for a real carpentry business with **15+ years of craftsmanship experience**. The project was developed to help a local business establish a strong online presence, showcase completed work, and enable customers to connect instantly through WhatsApp and phone.

> Live Demo: https://kotaiah-woodcraft-website.vercel.app/ 
> GitHub Repository: https://thesrinu7.github.io/Kotaiah-woodcraft-website/

---

## 📖 About the Project

This project was inspired by a real-world problem. My father has been working as a carpenter for over **15 years**, and most of his work came through word-of-mouth referrals. I built this website to help his business reach more customers, showcase completed projects, and make it easier for clients to request quotes online.

The website combines a premium wood-inspired design with practical business features such as WhatsApp inquiries, a furniture cost estimator, and local SEO optimization.

---

## ✨ Features

- Fully responsive design for **mobile, tablet, and desktop**
- Premium wood-themed modern UI
- Multi-page website (Home, About, Services, Gallery, Contact)
- WhatsApp inquiry with pre-filled customer messages
- One-tap phone calling
- Interactive Furniture Cost Estimator
- Before & After project showcase
- Project gallery with lightbox preview
- Sticky navigation with mobile hamburger menu
- Smooth scrolling and modern animations
- Dark/Light mode toggle
- Optimized image loading
- Local Business SEO using Schema.org JSON-LD
- GitHub Pages and Vercel deployment

## 🚀 Getting Started

Clone the repository:

```bash

```

Navigate to the project folder:


Open `index.html` in your browser or run it using VS Code Live Server.
